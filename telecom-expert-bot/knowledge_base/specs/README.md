# 3GPP Specification Documents

Place 3GPP specification documents in this directory for ingestion into the vector database.

## Supported Formats
- Plain text (.txt)
- Markdown (.md)

## Key Specifications
- TS 38.331 - RRC Protocol
- TS 38.413 - NGAP
- TS 38.473 - F1AP
- TS 38.321 - MAC
- TS 38.211 - Physical Channels
- TS 38.821 - NTN

## Ingestion
Use the `/knowledge` API endpoints or the `ingest_specs` method in `SpecRetriever`.
