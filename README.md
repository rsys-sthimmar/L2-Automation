# L2 Automation

This repository contains automation projects for telecommunications and networking.

## Projects

### [telecom-expert-bot](./telecom-expert-bot/)

A FastAPI-based Telecommunications Expert AI Bot specialized in 3GPP specifications (R15-R19).

Features:
- AI-powered Q&A for telecom specs (RRC, NGAP, F1AP, MAC, PHY, NTN)
- Protocol log analysis and decoding
- Automated test plan generation
- Knowledge management with approval workflow
- JWT authentication with master/child roles
- ChromaDB vector search for spec retrieval

See [telecom-expert-bot/README.md](./telecom-expert-bot/README.md) for full documentation.
